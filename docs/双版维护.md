# 鱼鱼小窝双版维护对照

以现役桌面体验为验收基准。两版共用的操作由同一组样例验收。各安装自行管理个人资料和服务接线。

| 使用场景 | 代码归属及对齐要求 |
| --- | --- |
| 自己和对方的资料 | 两版沿用家庭版小资料卡，在「我的资料」和「对方资料」之间切换，查看头像、昵称和个性签名。外观编辑共用 `panel/appearance.py` 与 `panel/web/assets/appearance.*`。连接诊断在控制台。 |
| 歌曲导入 | `panel/song_import.py` 与 `panel/web/assets/song-import.*` 共用。导入到当前安装的数据目录，保留原歌单、歌词及当前播放位置。 |
| 服务接入 | `panel/service_console.py` 与 `panel/web/assets/service-console.*` 共用可选生图、试听和诊断。发布版显示服务、桥接控制台、今天的账单和聊天连接。家用接线和受管理的本机服务由家用适配层负责。 |
| 桌面接口 | `panel/desktop_api.py` 共用。新增页面操作同时检查浏览器和桌面的接口清单。两版分别挂接托盘，验收窗口收起、恢复和退出，以及标题栏移动、缩放和输入框选字。 |
| 页面切换 | 发布版 `panel/web/index.html` 和家用界面覆盖层各自挂载页面。验收左栏常驻、跨页切换、聊天及日记草稿、浏览位置、歌曲连续播放。 |
| 日记和画册 | 发布版从用户数据目录读取按日 Markdown、配图和媒体索引。家用适配层继续使用自己的日记和现有画册。分别用外部更新的日记和合成图片验证。 |
| 聊天与开新鱼塘 | 通用窗口有文字、历史、图片和独立的隔离测试会话。发布版开新鱼塘在本地增加分隔；家用私聊还会请求远端归档。按连接能力验收语音收发和消息回执。 |
| 手机与家庭设备 | 两版都在「聊天连接」查看和开关手机入口，支持收发文图、同步头像和称呼、播放收到的语音。仓库版按需开启，使用一次性配对码和使用者的回环端口映射。家庭版启动时沿用原手机地址及授权，端口留空恢复家庭转发对应的端口。 |

## 素材与数据

两版共用应用图标：顶栏和托盘显示 `app-icon.png`，Windows 任务栏和浏览器标签使用 `app-icon.ico`。更换聊天头像不改变应用图标。仓库中的两个文件是家庭版对应品牌素材的独立副本，不依赖家庭版的安装目录。

仓库的初始个人素材只有 `default-me.png`、`default-peer.png`、`starter-rice.png`。新建资料库按需创建目录并提供一份白米饭。用户删除或已有同名食物时会保留其选择。家用资料重置到自己的默认素材。

聊天、角色资料、歌单、日记、媒体、账单、运行配置和令牌归各自的数据目录所有。在两版之间移植功能时按文件清单取代码，保留接收方的数据。

## 更新与验收

1. 先记录两版现有行为，确认涉及的通用功能、素材或连接能力。
2. 在仓库的通用模块修复，通过仓库回归后用家用维护脚本 `同步共用.py --apply` 更新冻结副本，再运行 `同步共用.py` 逐文件核对。页面装配差异分别在各自的适配层处理。
3. 仓库运行 `python -B tests/run.py --browser` 和 `python -B tools/scan_private.py`。家用用合成数据验证桌面和手机。涉及存储格式时，拿临时数据演练升级、回退、再次升级，核对旧记录和媒体原件。
4. 人工试用在独立测试会话里做一次文字往返。记录连接端、收发次数、缺测项和覆盖层加载方式。回退时按修改清单单项恢复源码，保留用户资料。
